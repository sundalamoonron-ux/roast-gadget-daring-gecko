One line roasting a gadget used every day: a smart fridge that texts you you're out of milk while you're standing right in front of it holding the carton.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
